
# Nutri Check-in App

App simples para gerenciamento de pacientes e check-in semanal (nutricionista + paciente).

## Como rodar no seu computador

1. Instale o Node.js (https://nodejs.org/)
2. Extraia este projeto para uma pasta, por exemplo `C:\nutri-app`
3. No terminal, dentro da pasta do projeto, rode:

```bash
npm install
npm start
```

4. Acesse no navegador:

- http://localhost:3000

## Login padrão do nutricionista

- E-mail: `nutri@example.com`
- Senha: `123456`

Depois de logado, você pode cadastrar pacientes e passar o e-mail/senha deles para acesso como paciente.

Para acessar pelo celular estando na mesma rede Wi-Fi, use o IP da sua máquina no lugar de `localhost`.
